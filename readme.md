<h1 align="center" id="title">Tela de Login/Cadastro</h1>
<p align="justify" class="description">A aplicação permite alternar entre os formulários de login e cadastro sem recarregar a página, oferecendo uma experiência de usuário fluida. Além disso, implementa validações básicas nos campos de entrada, como verificação de formato de e-mail e critérios de senha, fornecendo feedback visual em tempo real.</p>
  
![desktop-1](https://github.com/deivisondelmiro/login-page/assets/98898754/eb875b8b-300a-4536-8007-5322364064b1)

<h2>Funcionalidades</h2>

- Alternância entre formulários

- Validação de campos

- Feedback visual

<h2>Tecnologias Usadas</h2>

- HTML

- CSS

- JavaScript

<h2>Pontos Trabalhados</h2>

- Manipulação do DOM

- Módulos

- Regular expressions
